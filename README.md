Student Marks Analysis using Python

Project Description

This project performs basic Exploratory Data Analysis (EDA) using Python and Pandas. It analyzes student marks and displays statistical results.

Objectives

- Create a student dataset.
- Display the dataset.
- Calculate statistical information.
- Find average, highest, and lowest marks.
- Check missing values.

Technologies Used

- Python
- Pandas
- Pydroid 3

Dataset Details

Name| Marks
A| 80
B| 65
C| 90
D| 70
E| 85

Features

1. Displays the dataset.
2. Shows statistical summary using "describe()".
3. Calculates average marks.
4. Finds highest and lowest marks.
5. Identifies missing values.

Expected Results

- Average Marks: 78.0
- Highest Marks: 90
- Lowest Marks: 65
- Missing values: 0 in all columns

How to Run

1. Install Python and Pandas.
2. Save the code as "eda.py".
3. Run the program in Pydroid 3.
4. View the results in the output.

Conclusion

This project demonstrates basic EDA techniques and statistical analysis using Python and Pandas graphs.
